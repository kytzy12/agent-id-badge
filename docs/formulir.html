Agent ID Badge
Agent ID Badge is a free ERC-721 achievement badge on BNB Chain for Agent ID holders. Only wallets holding an Agent ID (name.ai) can mint one badge, verified on-chain at mint time. It gives Agent ID holders a verifiable on-chain identity credential.

Agent ID Badge uses Agent ID as the sole gate for minting. When a user mints, the contract calls balanceOf on the official Agent ID contract to verify the wallet holds an Agent ID (name.ai); wallets without one cannot mint. Each Agent ID holder can mint exactly one badge, so the badge is bound to their Agent ID identity. This gives Agent ID holders a verifiable on-chain credential and a concrete reason to use their Agent ID in a real application.
